# Neural Firing & Nonlinear Lab

A playground for experimenting with various activation functions in Deep Learning, from standard functions to original physics-inspired models.
深層学習における標準的な関数から、物理現象を模した独自モデルまで、様々な活性化関数を検証・実験するための遊び場です。

---

## Overview / 概要

This repository contains experimental code for activation functions. The goal is to explore how different nonlinearities affect neural network training, convergence, and "firing" patterns.
本リポジトリは、活性化関数の実験コードをまとめたものです。異なる非線形性がニューラルネットワークの学習、収束、そして「発火」パターンにどのような影響を与えるかを探究します。

Experimental results and detailed discussions are available at:  
実験の詳細な考察はブログで公開しています:  
👉 **[TUKUMO工房 (tukumolog.com)](https://tukumolog.com)**
